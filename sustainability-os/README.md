# Sustainability Team OS

Skalierung heißt nicht, sich selbst schneller zu machen — sondern das ganze Team besser.

Dieses Repo ist ein **Operating System für ein in-house Nachhaltigkeitsteam**: die geteilte Wissensbasis, die den kollektiven Kontext eines Teams in etwas verwandelt, das KI tatsächlich nutzen kann. Statt dass eine Person zum Flaschenhals für Kontext wird, kann sich jede:r selbst bedienen — und jede neue KI-Session weiß sofort, woran sie arbeitet.

Das Muster ist von Hannah Stulbergs [Team OS](../README.md) adaptiert und auf die Arbeitswelt von Nachhaltigkeitsteams übertragen: THG-Bilanzierung, Dekarbonisierungs-Roadmaps, ESG-Reporting (CSRD/ESRS), Lieferketten-Engagement und Stakeholder-Management.

## Beispielunternehmen

Alle Inhalte beziehen sich auf **Nordmark Industrie GmbH**, einen fiktiven mittelständischen Industriezulieferer (Metallverarbeitung, ~2.800 Mitarbeitende, CSRD-pflichtig ab Geschäftsjahr 2025). Namen, Zahlen und Ziele sind Platzhalter — sie zeigen die *Struktur*, nicht reale Daten. Ersetzt sie durch eure eigenen.

## Architektur in einem Satz

`CLAUDE.md`-Dateien auf jeder Ebene wirken als Wegweiser; ein Master-Index (`initiative-index.yaml`) verbindet jede Initiative mit all ihren Artefakten; Inhalte sind nach Funktion gegliedert (`programs/`, `carbon-data/`, `implementation/`, `reporting/`).

## Einstieg

- **Neu im Team?** → [`team/onboarding-guides/onboarding-general.md`](team/onboarding-guides/onboarding-general.md)
- **Überblick über alles?** → [`CLAUDE.md`](CLAUDE.md) (Root-Wegweiser)
- **Eine bestimmte Initiative?** → [`sustainability-development/initiative-index.yaml`](sustainability-development/initiative-index.yaml)
