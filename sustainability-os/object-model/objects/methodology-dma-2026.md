# Methodik: Doppelte Wesentlichkeit 2026

Das **Wie** hinter den Urteilen (Begründungs-Layer, Grundproblem C / Finding #3 —
früher nur in Köpfen).

1. Longlist von IROs aus ESRS-Themenliste + Branchenanalyse + Stakeholder-Input.
2. **Impact-Wesentlichkeit** = Schweregrad (Ausmaß × Umfang × Unabänderlichkeit) × Wahrscheinlichkeit.
3. **Finanzielle Wesentlichkeit** = Größe potenzieller Finanzeffekte × Wahrscheinlichkeit.
4. Schwellwert-Anwendung (`threshold-wesentlichkeit-2026`) → wesentliche Themen.

Jedes IRO trägt `scored_under: [methodology-dma-2026]` — so ist nachvollziehbar und
prüfbar, *nach welcher* Methode bewertet wurde.
