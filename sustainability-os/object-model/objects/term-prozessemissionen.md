# Begriff: Prozessemissionen

- **Definition:** Luftschadstoffe (z. B. NOx, Feinstaub), die direkt aus
  Produktionsprozessen der Metallverarbeitung freigesetzt werden.
- **Abgrenzung:** Nicht Prozesswärme-*Treibhausgase* (die zählen unter E1/Scope 1) —
  Prozessemissionen meinen die Luftschadstoffe unter E2.
- **Einheit / Berechnung:** t/Jahr je Schadstoff.

> Schließt die im Glossar-Review notierte Lücke („Prozessemissionen noch nicht definiert").
