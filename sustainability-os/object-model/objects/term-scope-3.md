# Begriff: Scope 3

- **Definition:** Alle übrigen indirekten Emissionen der Wertschöpfungskette (15 Kategorien
  lt. GHG Protocol), z. B. eingekaufte Güter, Transport, Produktnutzung.
- **Abgrenzung:** Weder eigene Quellen (Scope 1) noch eingekaufte Energie (Scope 2).
- **Einheit / Berechnung:** tCO₂e; Methodik je Kategorie (spend-based, supplier-specific, …).
