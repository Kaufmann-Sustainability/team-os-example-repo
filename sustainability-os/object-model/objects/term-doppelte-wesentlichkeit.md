# Begriff: Doppelte Wesentlichkeit

- **Definition:** Bewertung von Nachhaltigkeitsthemen nach Impact-Wesentlichkeit
  (Auswirkung auf Mensch/Umwelt) *und* finanzieller Wesentlichkeit (Auswirkung aufs Unternehmen).
- **Abgrenzung:** Mehr als reine Risikobetrachtung — beide Richtungen sind erforderlich (ESRS-Pflicht).
